- 原 history 直接返回最近 120 条 result_verified 记录，其中混有 PASS、重复对阵。旧页面把这些记录中的 Top1 命中计入战绩。
- 246 条发布行的 prediction frozen_at 都早于开赛，但仅检查此字段不够；还要检查对应正式 run 的 freeze_at 与 no_result_leakage 标志。
- 严格核验并排除重复、未发布后，当前接口返回 34 条。覆盖 20/34，首选 19/34，让球 13/25。此为当前返回样本，非全池、非 3.3 单版本命中率。
- 历史版本字段包含 2.3/2.4/2.5/2.7/3.2。不得重标为 3.3。当前无符合公开战绩条件的 3.3 记录。
- 公开接口未提供正式发布的理由、官方让球数、比分、半全场、总进球或 Best Play；页面明确缺项，不从内部原因字段拼凑，也不补算玩法。

## 接口变更

soren-public-api-v1 v2 保持旧调用（不带 client=1）的成功响应字段及 120 条上限。新增 client=1 的只读展示模式：排除重复；历史要求正式运行防泄漏标志、运行和预测冻结均早于开赛、核验赛果、SINGLE/DOUBLE 正式方向。只新增 frozenAt 与 pregameVerified 公共证据字段。所有返回均通过字段白名单映射。

无数据库迁移、删除或 UPDATE。保留 public-api-before.ts 供接口回滚。

## 回滚

网站切换提交只替换 index.html；回滚该提交即可恢复原首页，保留其他无关仓库历史。也可从 backup-pre-soren-client-20260917 取回 index.html，创建新提交推送 main；不要 force-push，不需回滚数据库。原 version.json 保持不变，旧页面恢复后不会因为此次发布造成版本循环刷新。

客户 API 若需单独回滚，用 public-api-before.ts 重新部署同名函数，verify_jwt=false 与原设置一致。前端在缺少赛前资格字段时不会展示历史命中率。
